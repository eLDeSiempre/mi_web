Árbol de Recursos (Miembros)

Haz clic en cada categoría para desplegar los enlaces. Esta guía se actualiza constantemente con lo mejor del sector.

01. Formación y Certificaciones

Donde aprender los fundamentos oficiales, desde gubernamental hasta las certificaciones más demandadas.

  • INCIBE Academia Hacker (Talleres): Talleres prácticos gratuitos y online. [Ir]
  • Microsoft Learn (Python): Ruta oficial para empezar con Python desde cero. [Ir]
  • Cisco Networking Academy: Para empezar con redes (CCNA) y ciberseguridad básica. [Ir]

02. Plataformas de Práctica (CTFs)

La teoría no sirve de nada sin práctica. Aquí puedes atacar máquinas vulnerables de forma legal.

  • Hack The Box: El estándar de la industria. Máquinas reales, laboratorios y desafíos. [Ir]
  • TryHackMe (Cyber Security 101): La ruta de entrada ideal para principiantes. [Ir]
  • PortSwigger Web Security Academy: Laboratorios gratuitos para aprender vulnerabilidades web (SQLi, XSS). [Ir]

03. Análisis de Red y Tráfico

Descubre qué está pasando en la red, desde puertos abiertos hasta paquetes sospechosos.

  • Nmap: El escáner de puertos y mapeador de redes por excelencia. [Ir]
  • Wireshark: El analizador de protocolos y tráfico de red más potente. [Ir]
  • Aircrack-ng: El kit de herramientas para auditar redes Wi-Fi. [Ir]

04. Seguridad Web (Pentesting)

La web es el campo de batalla más común. Estas son las herramientas para auditar aplicaciones.

  • Burp Suite: El proxy de interceptación web más usado por profesionales. [Ir]
  • OWASP ZAP: Alternativa gratuita y open-source a Burp Suite. [Ir]
  • SQLmap: Automatiza la detección y explotación de inyecciones SQL. [Ir]

05. OSINT (Inteligencia de Fuentes Abiertas)

La información es poder. Aquí tienes cómo recopilar datos sobre dominios, personas o empresas sin atacar directamente.

  • OSINT Framework: El mapa visual definitivo de herramientas OSINT. [Ir]
  • theHarvester: Herramienta para recopilar correos, subdominios y nombres de empleados. [Ir]
  • Shodan: El "Google de los dispositivos conectados a internet". [Ir]

06. Sistemas Operativos y Entornos

Necesitas un entorno preparado para el hacking. Estos son los sistemas operativos recomendados.

  • Kali Linux: El estándar de facto, con miles de herramientas preinstaladas. [Ir]
  • Parrot OS: Alternativa ligera y centrada en la privacidad. [Ir]
  • VirtualBox: El software gratuito para montar máquinas virtuales en tu PC. [Ir]

07. Bibliotecas y Wikis de Consulta

Cuando te enfrentas a algo nuevo, aquí es donde buscarás la técnica exacta.

  • HackTricks: La biblia de técnicas de pentesting y escalada de privilegios. [Ir]
  • MITRE ATT&CK: Base de conocimiento de tácticas y técnicas de atacantes reales. [Ir]
  • GTFOBins: Para escapar de entornos restringidos en Linux usando binarios del sistema. [Ir]

08. Comunidades y Noticias (En Español)

El networking es clave. Conecta con otros profesionales y mantente al día.

  • Hackplayers: La comunidad de seguridad informática más importante de España. [Ir]
  • DragonJAR: Foro histórico de seguridad informática en español. [Ir]
  • Incibe Noticias: Alertas de seguridad y noticias oficiales del gobierno. [Ir]
