# eLDeSiempre.es 🛡️

Plataforma web y aplicación móvil (APK) enfocada en ciberseguridad, hacking ético y educación. 

La estética visual está inspirada en una **Terminal Hacker / Mr. Robot**, con un diseño inmersivo, tipografía monoespaciada (Hack Nerd Font) y una paleta de colores oscura con acentos dorados.

## 🚀 Características Principales

- **Academia:** Módulos educativos desplegables sobre fundamentos de ciberseguridad.
- **Herramientas:** Arsenal clasificado en Análisis de Red, OSINT, CTF y Análisis de Malware.
- **Perfil Profesional:** Cada usuario puede registrar su experiencia, habilidades y enlaces (GitHub, HTB, TryHackMe...).
- **Chat Seguro:** Sala de comunicaciones en tiempo real (Firebase).
- **Premium:** (En desarrollo) Acceso a laboratorios privados y CTFs exclusivos.

## 🛠️ Arquitectura Técnica

*   **Frontend:** HTML, CSS y JavaScript puro (Vanilla JS). Sin frameworks pesados. Alojado en GitHub Pages.
*   **Backend:** API PHP alojada en un VPS propio con base de datos MySQL.
*   **Chat:** Firebase (Firestore) con reglas de seguridad configuradas.
*   **App Móvil:** WebView nativo de Android (Kotlin).
