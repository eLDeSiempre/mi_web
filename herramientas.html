Inspector de Cabeceras HTTP

Analiza las cabeceras de seguridad (CSP, HSTS, X-Frame-Options) de cualquier sitio web.

Ideal para: Auditar configuraciones web.

Analizador SSL/TLS

Comprueba la validez del certificado SSL, la fecha de expiración y la versión del protocolo de un dominio.

Ideal para: Verificar seguridad de servidores.

Generador de UUID

Crea identificadores únicos universales (v4) para tus pruebas de APIs y desarrollo.

Ideal para: Desarrollo de software seguro.

Probador de Expresiones Regulares

Prueba patrones de búsqueda (Regex) en tiempo real para validación de formularios.

Ideal para: Programación y filtrado de datos.

Formateador JSON

Valida y formatea documentos JSON para que sean legibles por humanos.

Ideal para: Análisis de APIs y logs.

Analizador de Robots.txt

Descubre qué directorios y archivos está intentando ocultar un sitio web a los buscadores.

Ideal para: Reconocimiento web (OSINT).

Validador de Seguridad Web

Comprueba si una web tiene protecciones contra Clickjacking, XSS y MIME-sniffing.

Ideal para: Auditoría de seguridad rápida.
